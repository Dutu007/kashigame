# 地图选择系统 V3

## 项目检查与范围

- 真实入口：`src/App.vue` 的 home → character → loading → MapPage。
- 原底图：`src/assets/kashgar-five-chapters-sparse.png`。旧的十关 `地图关卡*.png` / `map-overlays` 与现有五关构图不匹配，未混用。
- 实现：保留 Vue + SVG，未增加运行时依赖。`mapLevels.js` 保留五关名称、状态、标牌位置与 chapter；`mapVisuals.js` 补充统一百分比坐标。
- 路由：继续通过 `game/index.html?entry=map&chapter=weave|karez&hero=...` 进入。`game/shared/app.js` 的地图入口本来就允许两关进入，保留该规则，不套用目录页的进度锁。后三关仍为筹备中。
- 关卡原画：织梦巷 `game/levels/weave-lane/assets/scenes/02_weave_dream_lane/lane_market_bg.png`；坎儿井 `game/map-assets/SCN_L2_S.png`。已对照织坊、红蓝织物、雕花建筑、三口井、岩棚与梯子的视觉对应。没有改动实际关卡地图。

## 美术与保护

内置 imagegen 编辑原底图，输出 `src/assets/kashgar-city-v3.png`，完整提示词保存为同名 `.prompt.txt`。添加外围民居、街巷、台阶及连接建筑，调整巴扎商铺；保留现有原图作为可恢复来源。

新图不能保证生成过程完全不改变前两关细节，因此运行时另以不规则 SVG mask 叠加原底图的两处核心区。核心保持原像素，只有周边过渡羽化；两图共用同一坐标与光照方向，无矩形拼贴。高亮层复用这份合成场景，不使用另一张不同布局的图片。坎儿井保留原本干旱的地表空间，不把干井改成新水景。

## 交互

每关单一 polygon 同时用于热区、裁切、羽化与轮廓。互相接壤的巴扎和庭院已让出道路间隔。唯一 activeId 统一鼠标与键盘焦点。

300ms 局部提亮（1.06）与饱和度（1.10），300ms 后渐显低透明轮廓，650ms 后出现主题微光。持续光照周期约 3.2 秒；离开渐隐 350ms，提示卡 300ms。CSS 动画仅在当前区激活，无新建定时器/监听器积累。触屏点击、标牌键盘操作、Escape 及关闭后焦点恢复保留。系统减少动画时关闭循环与过渡。

布局由原图比例驱动，满宽或满高时剩余部分可滚动，不拉伸建筑、不裁掉关卡；窄屏提示左右滑动，键盘聚焦自动滚动到标牌。

## 素材限制

总地图仍是平面合成图，缺少与鸟瞰角度匹配的独立布幔、树叶分层。实际关卡有环境素材，但透视不一致，未强行复用，也未变形整栋建筑。当前织梦巷/巴扎/庭院采用织物与灯光缓慢变化，坎儿井采用井口微弱蓝绿反光，陶坊采用炉口暖光和极淡热气。真实布幔摆动、树叶摆动留待匹配素材后接入；没有用漂浮音符或大量粒子替代。

用户上传的要求在“对于缺少素材的区域”处截断，此处按已收到部分实现。

## 验证

`npm run build`；浏览器回归脚本 `scripts/check-map-v3.mjs` 从实际首页进入地图，覆盖五关热区、两关实际 iframe 路由、三关弹窗、快速划过退出、1024/390 宽窗口及 reduced-motion。截图与通过记录放在本目录。
