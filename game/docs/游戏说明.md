# 时间织城第二关当前游戏说明

第二关围绕坎儿井的水路维护展开。阿依苏与艾德在第一关“纹脉”后从喀什小镇来到坎儿井，先询问守井人，再通过井口清理、工具制作和井下检查逐步发现问题。开场对白只交代水量变少，不提前说明中段和下游的具体故障。

运行、按键、测试和校准入口统一见 [README](../README.md)。本说明对应当前代码中的可玩流程。

## 主线流程

| 顺序 | 玩家操作 | 完成后的变化 |
| --- | --- | --- |
| 1 | 与守井人对话 | 开放第一口井的清理 |
| 2 | 清理第一口井，再检查井口 | 发现旧梯子不能使用，开放三种材料 |
| 3 | 收集旧绳索、横踏杆、固定绑扎物 | 可回守井人处制作绳梯 |
| 4 | 完成绳梯装配、绑结和承重测试 | 准备三架绳梯，进入陶灯制作 |
| 5 | 和泥、转盘成型、拼接、守窑烧制，开窑取灯 | 获得油灯，完成下井准备 |
| 6 | 在第一口井布梯下井，检查上游水痕和水流 | 开放第二口井；从井梯返回地表 |
| 7 | 清理第二口井、布梯下井，疏通中段淤积 | 中段换为畅通底图，开放第三口井 |
| 8 | 清理第三口井、布梯下井，修补旧渠缺口 | 下游换为修复底图 |
| 9 | 在下游参照石处复查通水 | 可以回地表汇报 |
| 10 | 与守井人对话，保存维护记录 | 章节完成，可继续探索 |

每口井都必须先清理，再布梯。第一口井的清理与检查是两次互动；井口清理本身是单次操作。第一口井进入上游 UA，第二口井进入中段 UB，第三口井进入下游 UC。三段井下地图相互独立，必须回地表换井，不能沿地下边界走到另一段。未解锁的井不显示可操作提示。

## 绳梯制作

在守井人处打开地面工作台，依次完成以下操作：

1. 把四根横档拖到两条主绳之间，参考粉笔痕与脚印摆放步距。拉动两侧绳尾使横档水平；接近时自动吸附对齐。
2. 亲手完成两处关键连接：按提示穿绳并收紧。同伴补齐其余连接。特写展示主绳穿过木孔、绑绳绕过木条与主绳的关系。
3. 将沙袋放到每根横档中间的亮圈，每根测一次，共四次。接近目标松手后吸附，放稳并完成进度圈才算通过，拖动途中不判定。

承重测试也支持点击亮圈、点击放置按钮或按空格；方向键移动沙袋，回车放下。横档间距或绳结不合适时只返工对应位置，已通过的其他检查保留。完成后准备三架绳梯。

## 土陶油灯制作

### 和泥

点击泥团按压，按住时长影响力度；横向拖过泥团执行翻折。泥料需要同时满足均匀度、韧性、湿润度和气泡条件，不按固定点击次数通关。当前门槛为均匀度至少 0.78、韧性至少 0.68、湿润度在 0.52～0.88 之间、气泡不高于 0.24。

### 转盘成型

按住 `E` 控制转速，再按住亮圈沿陶坯外缘缓慢拖动，完成八个成型状态。只转盘或只拖动不能完成；转速过高、偏离轨道或拖动过快会增加歪斜。回到亮圈附近轻缓操作可以修复，主体稳定成型后进入拼接。

### 拼接

把低矮灯嘴拖到灯身右前侧，把环把拖到左后侧的接缝亮点。两件零件各有对应目标，接近后吸附；全部接好后进入烧制。布局、接缝融合和调色参数统一保存在 [LampAssemblyLayout.js](../js/LampAssemblyLayout.js)。

### 守窑烧制

烧制体验共 45 秒，完成后点击“开窑取灯”才获得可用油灯。

| 工序 | 时长 | 操作 |
| --- | --- | --- |
| 晾干入窑 | 4 秒 | 等待转场，不能添柴 |
| 小火预热 | 11 秒 | 控制火候，合适范围为 25～48 |
| 升温烧制 | 23 秒 | 控制火候，合适范围为 35～75 |
| 停火冷却 | 7 秒 | 停止添柴，等待取灯 |

点击柴堆、拖柴到窑口、点击添柴按钮或按空格均可添柴。添柴有 0.75 秒冷却，火候有升温惯性；提示采用回滞与延时，避免频繁闪变。火候偏差会给提示，但不倒扣进度、不延长总时长，也不要求返工。离线时间不累计烧制进度。

四段制作进度都可恢复。当前没有独立的挑杂质、装油、穿芯或试点窗口。

## 井下检查与维护

### 上游检查

在 UA 检查水痕和水流，确认这一段不是主要堵塞点。可以沿已布梯的井口返回地表，但必须完成上游检查才会开放第二口井。检查、作业和复查前需要用 `F` 点亮油灯。

### 中段清淤

靠近堵塞处按 `E` 进入局部作业模式，按以下顺序处理：

1. 扫开表层松沙两次。
2. 移开两侧碎石 R1 和 R2，先后顺序不限。
3. 取出内侧碎石 R3；两侧尚未腾空时会提示被卡住。
4. 清除残余淤积两次。

完成后退出局部作业，底图从 `MAP_UB_SILT` 切换为 `MAP_UB`。中途按 `Esc` 可退出并保留当前作业进度。

### 下游修渠

在 UC 缺口附近按 `E` 打开修渠工作台：

1. 观察上游冲刷、缺口承力边、下游水位三处线索。
2. 将底托石、侧楔石、压顶石分别放入对应落点；风化碎块不能代替修补石。
3. 沿水流方向依次压过五处接缝。
4. 将试流刻度调到 3，开闸检查稳定的小股水量。
5. 确认修补后，底图从 `MAP_UC` 切换为 `MAP_UC_FIXED`。

错误落位、压缝顺序或水量会显示现场反馈。按 `Esc` 退出时保存工作台进度。

### 复查与汇报

完成中段清淤和下游修补后，照亮下游参照石并按 `E` 复查。回地表与守井人对话，保存维护记录，完成章节。缺少清淤、修补或复查中的任一项时，守井人提示对应的未完成事项。

## 角色与对白

| 代码键 | 显示姓名 | 当前作用 |
| --- | --- | --- |
| `keeper` | 守井人 | 提供线索、制作入口与完成汇报 |
| `aysu` | 阿依苏 | 观察井口、水痕和环境变化 |
| `aide` | 艾德 | 检查结构、工具与地下作业 |

两位主角通过对白共同参与任务。统一项目在第一关选择艾德或阿依苏，第二关地表和井下自动沿用所选角色的原始待机、左右行走帧，视觉高度保持 184 逻辑单位。守井人使用独立的透明待机立绘：年长维护师傅、青色工作马甲、绳索和工具袋，靴底贴合地表，视觉高度同样为 184 逻辑单位。

主要对白统一保存在 [main.js 的 LINES](../js/main.js)，避免在文档中维护另一套逐字台词：`intro` 对应开场，`w01check` 对应第一口井检查，`ladderInvite` / `lampInvite` 对应制作引导，`uaInspect` 对应上游检查，`siltFixed` / `patchIntro` 对应清淤和修渠，`verified` / `report` 对应复查和汇报。玩家提示使用“第一口井”等称呼；UA、UB、UC 用于代码配置。

## 画面与移动

- 场景逻辑尺寸为 3072×1024，显示画布为 1920×1080，按窗口适配缩放。
- 地表和井下均支持空格跳跃，井下跳跃较低。行走高度由地面锚点折线计算；UB、UC 修复后使用各自的修复态地面线。
- 油灯根据朝向切换左右贴图，根据开关切换火焰与无焰贴图。井下有弱环境光、井筒光柱和以灯焰为中心的椭圆照明。
- 黑暗遮罩以半分辨率绘制，并按人物、相机和灯态变化更新。当前没有墙体遮光计算。
- UI 使用砂岩、羊皮纸、孔雀青和金色素材，包含目标、操作提示、人物对白、通知和制作工作台。边框按切片缩放，文字与交互由代码绘制。
- 当前使用整幅场景图表现清淤与修补前后的变化，部分井口与光照细节仍画在背景图内。

## 存档

主线保存在浏览器 `localStorage` 的 `twc_l2_save` 中。关键剧情、材料收集、制作完成、布梯、修复、复查和汇报等节点会保存。制作和修渠工作台保存各自的中断进度，退出或刷新后可以继续。

从统一入口退出或刷新时，会先保存当前工作台的实时制作状态；继续时恢复到保存的地表 / 暗渠场景。地表恢复到上次井口附近，暗渠恢复到该段的井底落脚点，不记录每一步的精确站位。存档属于当前浏览器与站点地址；换浏览器或端口不会自动共享。

统一入口 `index.html` 负责两关目录与通关衔接，第一关位于 `levels/weave-lane/`，第二关运行页为 `karez.html`。第一关完成回忆和收尾对话后解锁第二关，汇报并保存维护记录后显示第二关完成界面。两关可以返回目录后继续；跨关卡状态保存在 `twc_campaign_v1`，第一关主线保存在 `twc_l1_save`。
