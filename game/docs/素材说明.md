# 当前游戏素材说明

第二关场景、道具与 UI 图片放在 `map-assets/`，由 [main.js](../js/main.js) 和 [UISkin.js](../js/UISkin.js) 加载。第一关的专属素材放在 `levels/weave-lane/assets/`；两关的人物素材共用根目录 `assets/characters/`。合并项目只保留运行所需素材，已移除未参与游戏的 UI 参考稿、角色试验图和校准工具。

## 共享人物

[shared/characters.js](../shared/characters.js) 统一定义素材路径、帧数与 0.672 秒步态周期。阿依苏有 1 张待机、左右各 24 帧、上下各 22 帧；艾德有 1 张待机、四向各 24 帧，共 190 张动作帧。PNG 沿用第一关原文件，没有重新生成或修改像素。

第一关 Canvas 与第二关 [HeroActor.js](../js/HeroActor.js) 读取同一套定义。第二关只加载当前所选角色的待机与左右序列；使用原图脚底 y=335 的锚点贴合地面，高度按 184 逻辑单位缩放。行走动画速度随移速同步，始终贴地。油灯方向读取角色朝向，不依赖镜像整个人物。

守井人的透明待机立绘位于 `assets/characters/keeper/keeper_idle.png`，由 `BootScene` 加载为 `npc` 纹理，并建立只包含人物有效轮廓的 `body` 帧。地表按 184 逻辑单位等比缩放，靴底锚点贴合步行线。人物设计和生成提示词见 [守井人设计说明](../assets/characters/keeper/design.md)。

## 剧情转场插画

六张约 16:9 的 PNG 放在 `assets/transitions/karez/`：`arrival`、`descend`、`ascend`、`silt-cleared`、`water-restored`、`maintenance-record`。由内置 imagegen 参考本项目地表、暗渠、绳梯横档和陶灯生成，保持原场景的手绘笔触、暖色岩壁与青绿水流。原图不含字幕和人物全身立绘。

[KarezTransitions.js](../js/KarezTransitions.js) 通过 DOM 图片按需加载并复用缓存；开场与收尾另外叠加 `assets/characters/` 的原始人物 PNG，避免生成图改变角色外观。字幕、跳过按钮、人物位置与缓慢推镜由 [karez-transitions.css](../css/karez-transitions.css) 控制；系统减少动态效果设置会关闭动画。转场图片不作为 Phaser 全尺寸 GPU 纹理预加载。

每张图的剧情约束、参考图和实际生成提示词见 [转场素材设计说明](../assets/transitions/karez/design.md)。替换成图后递增 `KarezTransitions.js` 中 `artPath` 的版本，脚本和样式更新同时递增 `karez.html` 的对应版本。

## 当前 UI

运行图片位于 `map-assets/UI_RUNTIME/`，文件名为 `skin-*.png`，纹理键为 `skin_*`。

| 文件后缀 | 用途 |
| --- | --- |
| `goal` | 左上目标条 |
| `notice` | 操作与互动提示 |
| `dialogue` | 人物对话框 |
| `panel` | 完成与暂停等通知 |
| `workshop` | 绳梯、陶灯和修渠的大面板 |
| `card` | 工作区边框及侧边说明卡 |
| `confirm` | 提取金色与青色按钮 |

`prepareUISkin` 根据透明边界建立有效帧。横条使用九宫格，方框采用五段切片保护边角和中央装饰，大面板保持比例。所有文字、按钮点击区域和游戏物件由代码叠加。

## 更新素材

替换图片时保持文件名和纹理键一致，检查透明边缘、显示比例及锚点。若修改成型图的帧排布，需要同步检查 `LampFormingView.prepareFrames`；若修改零件尺寸，需要同步检查 `LampAssemblyLayout.js` 中的布局和接缝参数，并进入陶灯工作台验证。

图片版本号的更新位置和运行检查见 [README](../README.md)。仅供预览的截图放在 `output/`，不要混入运行素材目录。
