## 当前 UI

运行图片位于 `map-assets/UI_RUNTIME/`，文件名为 `skin-*.png`，纹理键为 `skin_*`。

| 文件后缀 | 用途 |
| --- | --- |
| `goal` | 左上目标条 |
| `notice` | 操作与互动提示 |
| `dialogue` | 人物对话框 |
| `panel` | 完成与暂停等通知 |
| `workshop` | 绳梯、陶灯和修渠的大面板 |
| `card` | 工作区边框及侧边说明卡 |
| `confirm` | 提取金色与青色按钮 |

`prepareUISkin` 根据透明边界建立有效帧。横条使用九宫格，方框采用五段切片保护边角和中央装饰，大面板保持比例。所有文字、按钮点击区域和游戏物件由代码叠加。

[UI 素材目录](../UIdesign/catalog.html) 展示当前使用的源图和运行图；其数据与处理提示词统一来自 [processing.json](../UIdesign/processing.json)。原始设计图保留在 `UIdesign/` 作为美术参考，不在游戏启动时加载。

## 更新素材

替换图片时保持文件名和纹理键一致，检查透明边缘、显示比例及锚点。若修改成型图的帧排布，需要同步检查 `LampFormingView.prepareFrames`；若修改零件尺寸，需要在 [拼接工具](../tools/assembly-tuner.html) 中检查布局。

图片版本号的更新位置、运行检查和工具入口见 [README](../README.md)。仅供预览的截图放在 `output/`，不要混入运行素材目录。
